# User Guide: Run the Software

Follow these steps to run the software locally.

## 1) Install prerequisites

Make sure Python and pip are installed.

## 2) Install MkDocs Material (for this documentation)

```bash
pip install mkdocs-material
```

## 3) Run the software

Use the software's run command in your environment:

```bash
posdoc
```

If your setup uses a different command, replace `posdoc` with that command.

## 4) Open the documentation

To preview this user guide in a browser:

```bash
mkdocs serve
```

Open `http://127.0.0.1:8000`.
